# Module 01 — Foundations

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Local setup](../setup.md)

## Purpose

Build a mental model of Ethereum as a replicated state machine. Observe accounts, transactions, and blocks on a disposable local chain before introducing Solidity.

## Learning objectives

1. Explain what an Ethereum state transition changes.
2. Trace an ETH transfer from request to receipt.
3. Explain the difference between inclusion, canonicality, and finality.

## Workflow

1. Read the textbook chapter.
2. Predict before you run the example.
3. Complete the exercise from its written requirements and save your evidence.
4. Review your answers and repeat any experiment you cannot explain.
5. Submit the [100-point assessment](assessment.md) after all three lessons.
