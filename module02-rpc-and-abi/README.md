# Module 02 — RPC and ABI

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Foundations](../module01-foundations/README.md)

## Purpose

Follow the boundary between an application and an Ethereum node. Read raw RPC results, distinguish simulation from broadcast, and encode contract call data.

## Learning objectives

1. Read a JSON-RPC request and interpret its response.
2. Distinguish a simulated message call from a broadcast transaction.
3. Encode a function call from its canonical signature and arguments.
