# Module 03 — Solidity Foundations

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [RPC and ABI](../module02-rpc-and-abi/README.md)

## Purpose

Write and deploy small contracts. Learn how types, storage, caller context, and errors determine observable behavior.

## Learning objectives

1. Compile, deploy, and call a minimal Solidity contract.
2. Choose value and reference types for on-chain records.
3. Use msg.sender and msg.value to enforce function requirements.

## Workflow

1. Read the textbook chapter.
2. Predict before you run the example.
3. Complete the exercise from its written requirements and save your evidence.
4. Review your answers and repeat any experiment you cannot explain.
5. Submit the [100-point assessment](assessment.md) after all three lessons.
