# Module 04 — Contract Interfaces

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Solidity Foundations](../module03-solidity-foundations/README.md)

## Purpose

Connect contracts to users and observers. Learn what logs reveal, what payable calls transfer, and how state machines enforce authorization.

## Learning objectives

1. Read an event from a transaction receipt.
2. Trace ETH into and out of a contract.
3. Specify allowed transitions with guards and observable effects.

## Workflow

1. Read the textbook chapter.
2. Predict before you run the example.
3. Complete the exercise from its written requirements and save your evidence.
4. Review your answers and repeat any experiment you cannot explain.
5. Submit the [100-point assessment](assessment.md) after all three lessons.
