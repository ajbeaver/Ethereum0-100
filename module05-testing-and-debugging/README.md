# Module 05 — Testing and Debugging

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Contract Interfaces](../module04-contract-interfaces/README.md)

## Purpose

Turn execution assumptions into tests. Learn how to isolate actors, compare traces, and exercise a family of inputs.

## Learning objectives

1. Write isolated Forge tests for success and rejection.
2. Read a call tree and identify the first relevant failure.
3. Use fuzz input to check a rule over many examples.

## Workflow

1. Read the textbook chapter.
2. Predict before you run the example.
3. Complete the exercise from its written requirements and save your evidence.
4. Review your answers and repeat any experiment you cannot explain.
5. Submit the [100-point assessment](assessment.md) after all three lessons.
