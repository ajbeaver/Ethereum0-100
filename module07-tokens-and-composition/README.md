# Module 07 — Tokens and Composition

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Smart Contract Security](../module06-smart-contract-security/README.md)

## Purpose

Learn to read ERC interfaces and reason about authority across contracts. Compare fungible balances, unique ownership, and external dependencies.

## Learning objectives

1. Distinguish native ETH from a token’s internal ledger.
2. Contrast token IDs with fungible balances.
3. Identify trust boundaries at external addresses.

## Workflow

1. Read the textbook chapter.
2. Predict before you run the example.
3. Complete the exercise from its written requirements and save your evidence.
4. Review your answers and repeat any experiment you cannot explain.
5. Submit the [100-point assessment](assessment.md) after all three lessons.
