# Module 09 — Networks and Operations

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Off-chain Indexing](../module08-off-chain-indexing/README.md)

## Purpose

Compare L1 and L2 execution contexts. Make deployment identity explicit and design a repeatable local operating procedure.

## Learning objectives

1. Validate network identity before a write.
2. Describe what a rollup executes and what it uses L1 for.
3. Describe safe local deployment, smoke testing, and reporting.

## Workflow

1. Read the textbook chapter.
2. Predict before you run the example.
3. Complete the exercise from its written requirements and save your evidence.
4. Review your answers and repeat any experiment you cannot explain.
5. Submit the [100-point assessment](assessment.md) after all three lessons.
