# Module 10 — Lab Escrow Capstone

**Course:** Ethereum 0–100, Edition 1  
**Prerequisite:** [Networks and Operations](../module09-networks-and-operations/README.md)

## Purpose

Build and demonstrate a small local ETH escrow. Combine guarded state transitions, pull payments, reproducible deployment, and a replayable Python indexer.

## Learning objectives

1. Translate a transition table into a small public interface.
2. Build a Python SQLite projection from the four capstone events.
3. Demonstrate the system from a clean local chain and empty database.
